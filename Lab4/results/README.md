# Role A Results

This directory stores Role A experiment outputs.

| File | Content |
|---|---|
| `env_info.txt` | Collected local environment information |
| `single_inference_output.txt` | Single `llama-cli` inference output |
| `single_benchmark.csv` | Baseline benchmark raw records |
| `single_benchmark_summary.md` | Baseline benchmark grouped summary |
| `param_tuning.csv` | Parameter tuning raw records |
| `param_tuning_summary.md` | Parameter tuning grouped summary |

`max_rss_kb` was not measured in the current Windows environment. Raw CSV cells remain empty for that column, and Markdown summaries mark it as `not measured on Windows`.
