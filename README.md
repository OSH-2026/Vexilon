### 项目简介

这是中国科学技术大学2026春季学期 OSH-2026 的课程小组 `Vexilon` 的项目仓库。

#### 我们要做什么？

将 IronClaw 轻量化地集成到 Huawei LiteOS 中，并利用 Rust 语言的内存安全特性，实质性提升嵌入式系统的安全性。

我们不仅仅是移植代码，而是致力于实现一个完整的技术示范，展示如何为资源受限的物联网终端设备，安全、优雅地引入本地智能与可编程能力。

#### 项目的核心产出是什么？

1.  **一个可集成的 LiteOS 组件 (`ironclaw_lite`)**：符合 LiteOS 组件标准，提供简洁的 C API，使任何 LiteOS 应用都能方便地加载和执行安全的 WASM 工具。
2.  **一个用 Rust 重写的安全内核 (`rust_ironclaw_core`)**：这不是完整的 IronClaw，而是一个专为本项目构建的、内存安全的 WASM 运行时管理核心。它是对 LiteOS 纯 C 环境的关键安全增强。
3.  **一个端到端的演示应用 (“会说话的温湿度计”)**：完整展示从“自然语言规则” -> “Rust编写WASM工具” -> “在设备端安全执行” -> “驱动硬件响应”的全流程。它是项目所有技术点的可视化验证。
